# PerfectMatch — сайт

Статический сайт HR-консалтинговой компании PerfectMatch (основатель — Павел Ясин).

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Главная |
| `hr-as-a-service.html` | HR-as-a-Service (внешний HR-департамент) |
| `rpo.html` | RPO / подбор персонала |

## Стек

Чистые HTML, CSS и JavaScript — без сборки и зависимостей. Достаточно открыть `index.html`.

```
assets/
  css/style.css   — все стили (дизайн-токены в :root)
  js/main.js      — прелоадер, меню, анимации появления, счётчики, карусель отзывов, форма
  img/            — логотипы, фото, логотипы компаний-клиентов
```

## Локальный запуск

```bash
python3 serve.py
```

Откроется на `http://localhost:8420` с отключённым кешем — удобно при правках.

## Что нужно доделать перед боевым запуском

- **Форма заявки** сейчас формирует письмо через `mailto:` (сайт статический, бэкенда нет).
  Заменить обработчик в `assets/js/main.js` на реальный endpoint — Formspree, вебхук CRM
  или скрипт на хостинге. Разметку менять не потребуется.
- Добавить страницу политики конфиденциальности (в подвале сейчас текст без ссылки).

## Дизайн

- Шрифты: Manrope (заголовки), Inter (текст)
- Акцентный цвет: `#3157FF`
- Боковые отступы 40px (22px на мобильных), отступы между блоками 85px (70px на мобильных)
- Минимальный кегль: 16px на десктопе, 14px на мобильных
